# x

Use these tools for live X (Twitter) data. They are read-only. Do not post, like, follow, or send messages.

- `search_posts`: recent posts, last 7 days. Put operators in `query` when you need them (`from:username`, `lang:zh`).
- `search_users`: find accounts by a name or keyword.
- `lookup_user`: one account by username, without the @.

Prefer a short query. Quote the post url you actually got back. Do not invent posts or follower counts. If a tool says the archive is closed, search the last 7 days instead.
